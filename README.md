Hola, som el grup 14 i a continuació us presentem el nostre projecte, el qual consisteix en el desenvolupament d'un codi de Python per a optimitzar y automatitzar la gestió y asignació de portes d'embarcament (gates) en un aeroport. L'objectiu principal es processar els vols que entren i assignar una porta disponible respectant les restriccions reals com la distribució de terminals per aerolínies i de la zona Schengen i No Schengen.
